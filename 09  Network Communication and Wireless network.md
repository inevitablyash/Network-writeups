# Network Communication Types

## Unicast
- One sender → One receiver  
- Direct communication between two devices  

### Example
- Opening a website from your laptop  

---

## Multicast
- One sender → Multiple selected receivers  
- Data sent only to subscribed devices  

### Example
- Live video streaming  

---

## Anycast
- One sender → Nearest receiver in a group  
- Uses routing to send data to the closest server  


---

## Broadcast
- One sender → All devices in the network  
- Every device receives the message  
  

---

# Quick Summary

| Type | Communication |
|---|---|
| Unicast | One → One |
| Multicast | One → Many (selected) |
| Anycast | One → Nearest |
| Broadcast | One → All |
