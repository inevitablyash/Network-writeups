# Designing the Cloud

## 1. Virtual Networks
- Software-based networks inside the cloud  
- Allow secure communication between cloud resources  
- Isolated from other users (multi-tenant environment)  

---

## 2. Server Farm
- Collection of multiple servers (e.g., 100 computers)  
- Works together to handle large workloads  
- Improves performance, scalability, and availability  

---

## 3. Network Function Virtualization (NFV)
- Replaces physical networking devices with virtual ones  
- Examples:
  - Virtual routers  
  - Virtual firewalls  
- Reduces hardware cost and increases flexibility  

---

## 4. Connecting to the Cloud
- Methods to connect local systems to cloud infrastructure:
  - Internet connection  
  - Dedicated connection (e.g., leased line)  
  - Hybrid setups  

---

## 5. Virtual Private Network (VPN)
- Secure connection over a public network (Internet)  
- Encrypts data during transmission  
- Used for remote access and site-to-site connectivity  

---

## Key Idea
Cloud design focuses on **virtualization, scalability, and secure connectivity** using software-defined infrastructure.
