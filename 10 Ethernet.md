# Ethernet Standards

Ethernet is a standard used for wired network communication.

---

# Ethernet Naming Convention

Ethernet standards are written in a format such as:

`1000BASE-T`

## Notation Breakdown

| Part | Meaning |
|---|---|
| 1000 | Speed in Mbps |
| BASE | Baseband transmission |
| T | Cable type |

---

# Common Ethernet Standards

| Standard | Speed | Cable Type | Maximum Distance |
|---|---|---|---|
| 10BASE-T | 10 Mbps | Copper (Twisted Pair) | 100 m |
| 100BASE-T | 100 Mbps | Copper | 100 m |
| 1000BASE-T | 1 Gbps | Copper | 100 m |
| 10GBASE-T | 10 Gbps | Copper | 100 m |

---

# Copper Cabling

Uses electrical signals to transmit data.

## Common Types
- Cat5e  
- Cat6  
- Cat6a  

## Features
- Affordable  
- Easy to install  
- Limited distance compared to fiber  

---

# Fiber Optic Cabling

Uses light signals instead of electricity.

## Types

### Single Mode Fiber (SMF)
- Long-distance communication  
- Small core size  
- Laser light source  

### Multi Mode Fiber (MMF)
- Shorter distances  
- Larger core size  
- LED/light source  

## Features
- Faster speeds  
- Longer distances  
- Resistant to electromagnetic interference (EMI)  

---

# Common Fiber Standards

| Standard | Speed | Fiber Type |
|---|---|---|
| 1000BASE-SX | 1 Gbps | Multi Mode Fiber |
| 1000BASE-LX | 1 Gbps | Single Mode Fiber |
| 10GBASE-SR | 10 Gbps | Multi Mode Fiber |
| 10GBASE-LR | 10 Gbps | Single Mode Fiber |

---

# Connectors

## Copper Connectors

### RJ45
- Standard Ethernet connector  
- Used with twisted-pair cables  

---

## Fiber Connectors

### ST
- Twist-lock connector  

### SC
- Push-pull connector  

### LC
- Small form-factor connector  
- Common in modern networks  

---

# Quick Notes

- Copper = electrical signals  
- Fiber = light signals  
- Fiber supports higher speeds and longer distances  
- RJ45 is the most common Ethernet connector
